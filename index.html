What did the community approve?

Supported policy format

1–12 ordered NATIVE_TRANSFER or ERC20_TRANSFER actions. Each action has kind, recipient, asset, amount, purpose. Native asset is the zero address. All amounts are positive base-unit decimal strings. Arbitrary calls, approvals, and delegate calls cannot pass.

What is about to happen?

Bundle format and review scope

1–16 transactions, each with to, value (decimal string), data (hex bytes), operation (0 = call, 1 = delegate call), and purpose. Only exact native/ERC-20 transfers committed in the policy can pass. Chain, treasury, count, order, destination, amount, selector, and all calldata bytes are enforced.
